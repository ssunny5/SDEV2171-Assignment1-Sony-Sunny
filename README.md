## Getting Started

1. Create your own repository from this GitHub template.
2. Clone your repository to your computer.
3. Create a new Expo project inside your repository.
4. Open your project in Visual Studio Code.
5. Follow the requirements in the Assignment 1 Specifications.
6. Complete and test your application.
7. Commit your work regularly.
8. Push your work to GitHub.

## Submission

Your GitHub repository is your assignment submission.

Before the deadline:

- Make sure your complete project has been pushed to GitHub.
- Make sure your latest changes have been committed and pushed.
- Make sure your project runs correctly.
- Make sure your name is included wherever required.

Submit the URL of your GitHub repository through Brightspace.
