# Detailed Rubric

## Environment Setup (5 marks)

| Level | Description |
|------|-------------|
| **Excellent (5)** | Expo project created correctly from scratch. Application runs successfully on emulator or physical device. Project structure is clean and appropriate. |
| **Good (4)** | Expo project created correctly and runs successfully. Minor issues with project organization or setup but overall functional. |
| **Satisfactory (3)** | Application runs but setup shows inconsistencies (e.g., incorrect configuration, missing or confusing structure). |
| **Needs Work (2)** | Application runs inconsistently or only partially demonstrates correct Expo setup. |
| **Poor / Incomplete (0-1)** | Application does not run or project was not created correctly using Expo. |

---

## Navigation (5 marks)

Navigation will be evaluated by running the app and verifying that all required screens can be accessed through the user interface.

| Level | Description |
|------|-------------|
| **Excellent (5)** | Navigation works correctly between all required screens (Home, Sleep Log Entry, Sleep Statistics). The Home screen includes clear navigation controls to both screens. Tab navigation (if retained) is properly updated and routes correctly. |
| **Good (4)** | Navigation between all screens works, but minor usability or structural issues exist (e.g., unclear navigation elements, minor routing inconsistencies). |
| **Satisfactory (3)** | Navigation allows access to all screens but contains noticeable issues such as confusing layout, inconsistent navigation patterns, or partially updated tab navigation. |
| **Needs Work (2)** | Navigation only partially works (for example, one screen is difficult to access or routing is inconsistent). |
| **Poor / Incomplete (0–1)** | Navigation is missing, broken, or prevents access to required screens. |

---

## Functional UI Requirements (5 marks)

| Level | Description |
|------|-------------|
| **Excellent (5)** | All required UI elements are implemented correctly: Home screen content, Sleep Log Entry inputs, and Sleep Statistics grid. Layout is clear and all required information is present. |
| **Good (4)** | All required screens and most UI elements are present and functional, with only minor omissions or layout issues. |
| **Satisfactory (3)** | Required screens exist but some UI elements are incomplete, unclear, or inconsistently implemented. |
| **Needs Work (2)** | Several required UI elements are missing or poorly implemented. Screens may appear incomplete or confusing. |
| **Poor / Incomplete (0–1)** | Major UI requirements are missing or the screens do not meet the assignment specifications. |

---

## Code Organization (1 mark)

| Level | Description |
|------|-------------|
| **Excellent (1)** | Code is clearly organized with meaningful file names, logical structure, and appropriate use of reusable components. |
| **Good (0.75)** | Code is generally organized and readable with only minor structural issues. |
| **Satisfactory (0.5)** | Code functions but organization, naming, or component structure could be improved. |
| **Needs Work (0.25)** | Code is difficult to follow due to poor structure, naming, or lack of component organization. |
| **Poor / Incomplete (0)** | Code is poorly organized, difficult to read, or incomplete. |

---

## Reflection (4 marks)

All reflection questions must be answered to be eligible for full marks.

| Level | Description |
|------|-------------|
| **Excellent (4)** | Reflection fully addresses all prompts with clear, thoughtful responses. Answers reference specific files, components, commits, or code from the project. Explanations demonstrate strong understanding of navigation, component reuse, and development workflow. |
| **Good (3)** | Reflection addresses most prompts clearly and demonstrates good understanding of the project. Some references to project files, components, or commits are included, though explanations may lack depth or detail. |
| **Satisfactory (2)** | Reflection answers the prompts but responses are brief, general, or lack clear references to specific parts of the project. Understanding of concepts is present but somewhat limited. |
| **Needs Work (1)** | Reflection responses are incomplete, very brief, or demonstrate minimal understanding of the project. Few or no references to specific code, files, or commits. |
| **Poor / Incomplete (0)** | Reflection missing, extremely incomplete, or does not address the required prompts. |
